## Talking points to anchor any resume bullet

- **Reasoning loops, not workflows** — every step shows plan/critique loops and a replan edge.
- **HITL by design** — approval gate is the only path to CRM writeback.
- **Server-side AI boundary** — keys never reach the browser; degraded mode is the default.
- **Brand-safe by construction** — evaluator runs on every customer-visible string with a forbidden-terms list.
- **Auditable** — every action lands in a chronological audit log with model, tokens, latency, evaluator score, and approver.
